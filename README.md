The funniest possible last text a phone sends at one percent battery — one tight line, in the phone's own voice, with the punch landing at the end.

`main.py` (Python, standard library only) writes the entry line to `/output/entry.txt` as UTF-8, then re-reads it and asserts it is byte-identical to what was written.

## Run it

```sh
python3 main.py
```

The entry line lands in `/output/entry.txt`.
